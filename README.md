# ICU文法ドリル

ICU（国際基督教大学）一般選抜 英語 Reading の文法・語彙問題（2014–2025年、207問）を解く静的サイトです。

- `index.html` … サイト本体（外部ライブラリなし・1ファイル）
- `data/bank.json` … 問題（Part II 空所補充 166問 ＋ Part I 語彙・語法 41問）
- `data/passages.json` … 年ごとの Part II 全文と Part I 該当段落
- `data/glosses.json` … 単語の意味（中国語・日本語）
- `data/trend.md` … 出題傾向（「傾向」ページに表示）

## 機能
- 単語タップで意味（中国語＋日本語）
- ランダム出題（範囲・カテゴリ・5/10問。間違えた問題と苦手カテゴリを優先）
- 年度別全文（空欄を順に解く・タイマー任意・同年の Part I 問題つき）
- 苦手復習（間違いの多い順）
- 統計（全体・カテゴリ別・タグ別・よく間違える問題・年別）と「記録をコピー」

## 注意
- 2025年は公式解答。それ以外の年の解答は自己解答で、公式のものではありません（自信度が低いものは表示あり）。
- 学習記録はブラウザの localStorage（キー `icu_grammar_v1`）にのみ保存され、どこにも送信されません。

## ローカルで見る
`fetch` でデータを読むため、ファイルを直接開かずにサーバー経由で開いてください。

    python3 -m http.server 8000
    # → http://localhost:8000/
