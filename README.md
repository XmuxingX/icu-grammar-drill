# ICU文法ドリル

ICU（国際基督教大学）一般選抜 英語 Reading の文法・語彙問題（2004–2025年、452問）を解く静的サイトです。

- `index.html` … サイト本体（外部ライブラリなし・1ファイル）
- `data/bank.json` … 問題（Part II 空所補充 366問 ＋ Part I 語彙・語法 86問）
- `data/passages.json` … 年ごとの Part II 全文と Part I 該当段落
- `data/glosses.json` … 単語の意味（中国語・日本語）。サイトに出てくる語だけを収録
- `tools/build_glosses.py` … glosses.json の不足語を辞書データから補うスクリプト
- `data/trend.md` … 出題傾向（「傾向」ページに表示）

## 機能
- 単語タップで意味（中国語＋日本語）。問題文・選択肢・解説・全文のすべての英単語をタップ可能（変化形は原形も表示。辞書にない固有名詞などは「意味データなし」）。「✓ わからない」でチェックすると、問題文の中で色＋波線の印がつく
- チェックした単語の一覧（チェック回数の多い順・出題された問題・日付・個別に削除可）
- ランダム出題（範囲・カテゴリ・5/10問。間違えた問題と苦手カテゴリを優先）
- 年度別全文（2004–2025年。空欄を順に解く・タイマー任意・同年の Part I 問題つき）
- 苦手復習（間違いの多い順）
- 統計（全体・カテゴリ別・タグ別・よく間違える問題・年別）と「記録をコピー」

## 注意
- 2025年は公式解答。それ以外の年の解答は自己解答で、公式のものではありません（自信度が低いものは表示あり）。
- 2004–2013年（245問）は公式の解答がないため推定解答です（`answer_source: "derived"`）。解説の下に「※公式解答なし・推定解答」（確度がやや低いものは「（確度やや低め）」つき）と表示します。
- 学習記録はブラウザの localStorage（キー `icu_grammar_v1`）に、チェックした単語は別キー `icu_grammar_unknown_v1` にのみ保存され、どこにも送信されません。
